## Adding A Template

1. Open `lib/templates.ts`.
2. Add a new object to `templates`.
3. Include:
   - `slug`
   - `name`
   - `shortName`
   - `category`
   - `description`
   - `features`
   - `sections`
   - `image`
4. Confirm the page appears at:

```txt
/templates/[slug]
```

## Copy Principles

- Lead with launch speed.
- Keep CTA labels direct.
- Use premium, concise language.
- Avoid generic web design claims.
- Focus on coaches, consultants, mentors, freelancers, and service businesses.
